# AC／报价审稿市场：实现与初步评估

日期：2026-11-10。基础：本地 main `ad5a586`。
实现分支：`codex/ac-review-market`。旧工作区修改保持原样。

## 实际实现的机制

审稿人主动报价，作者提出最低 AC 和支付份额上限。市场按每轮开始时的
审稿人 AC 快照分桶，最多抽样 5 人。过滤自审、AC 不达标和超预算后，
按 AC／报价排序，审稿人确认接单，再锁定报价并进入原有审稿流程。
AC 不是审稿质量保证，也不是引用贡献的因果估计。零 AC 同分时随机。
报价第一版为可覆盖的固定策略，没有强制压价或学习报价。

第一版支持固定启发式与随机策略、连续和离散审稿。旧 RL/DQN 策略没有
新市场动作适配，新模式遇到它们会明确报错；没有进行 RL 训练。
所有配置与代码接口见 `ac_review_market.md`。

## 首先判断是否正常运行

1. 每个 timestep，每个 agent 只使用一次劳动时间。
2. 同一论文不被重复审稿，同一 agent 不重复接单，状态双方一致。
3. 份额有限、非负且加总为 1；总 agent AC 等于总论文 AC。
4. 报价受预算和作者持有份额约束，成交后不被后续报价改变。
5. 每篇论文每轮搜索有上限，不调用旧全量价格表和全量匹配。
6. 多步运行仍能写作、发表、审稿和结算；没有强制保证成交率。

新市场测试共 13 项通过。旧测试 79 项在修改前后同样有 4 个失败和
1 个错误，没有新增回归。除了项目已列出的四个旧失败，本地 main 还
预先存在 `test_subthreshold_review_consumes_opportunity_without_reward`
错误：默认门槛为 0，测试传入 -0.5 努力而触发非负校验；它不是这次新增。
完整前后日志位于 `experiments/ac_review_market/`。

## 再判断影响是否值得接受

主对照使用 32 个 agent（启发式与随机各半）、1000 步、5 个配对种子
11/22/33/44/55，每人起始两篇零 AC 论文。报价为 0.25%、0.5%、1%，
按 agent 顺序分配，与初始 talent 独立。相同种子保持初始世界相同，
后续随机行动路径不会完全相同。逐步运行会检查上述劳动、容量与记账不变量。

五个实验组：

- 旧市场：原始公式定价与分配。
- 同价旧分配：使用与新市场相同的个人报价，保留旧分配和参与判断。
- 新市场：AC／报价排序，每轮每篇论文最多查看 5 人。
- 全候选：同一新市场，但查看所有候选人，评估有限搜索的影响。
- 随机排序：同一新市场、报价与抽样，随机选择合格者，评估排序规则。

下面均为五个种子的均值，不能据此声称普遍或长期均衡。

## 需要谨慎区分的解释

作者净增益是在同一篇论文、不审稿的基线下计算，扣除了支付份额的持续收益
成本和已积累 AC 转让成本；没有包含作者／审稿人放弃写作的全部反事实，
因此不是社会总福利。模型内增值也不是真实引用增量。本地 main 使用的是
自身的论文 accrual 模型。

与旧市场比较是整套机制变化的结果；同价旧分配减少定价差异，但参与和接单
逻辑仍不同。随机排序对照更接近检验 AC／报价规则本身；配对均值及其标准误
保存在结果 JSON 中。五个种子仍不足以证明一般性的因果改善。

实际结果体现了取舍：应同时检查产出、模型内贡献、作者净收益、劳动分配、
等待和订单集中程度。订单集中和资本集中是不同指标，不能混为一谈。
初步结果不能只因为总 AC 或审稿增值增加就判为成功。

建议下一轮事先约定可接受的论文产出下降、等待增加和订单集中程度，再用
更多种子、报价尺度和候选数检验。这里没有为通过评估添加配额、补贴或自动
平衡控制器。当前写作占比是经济与策略的结果，不能直接称为科学意义上的健康比例。

另有 16 个 agent、300 步、五种子的较短四组对照，位于
`experiments/ac_review_market/results.json`，用于检查较小规模下的行为。

## 复现

```powershell
python -m unittest test_review_market -v
python compare_review_markets.py --steps 1000 --agents 32 --seeds 11,22,33,44,55 --output experiments/ac_review_market_long
```

后续运行会重新生成五组结果。正式市场保持 `legacy` 默认，用
`--market-mechanism sampled_bidding` 显式启用，便于对照和逐步采用。
