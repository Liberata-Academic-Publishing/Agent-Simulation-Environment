# AC／报价市场：单轮 simulation 结果

本轮已完成，没有运行 RL 训练。运行脚本：`run.py`；原始数据为
`history.json`，概要为 `summary.json`，终端日志为 `run.log`。

## 设置

- 20 个启发式 agent、20 个随机 agent，连续审稿，1000 步，seed=11。
- 使用正常的 `build_simulation()` 初始化，每人 10 篇初始论文，共 400 篇。
- 市场最多抽样 5 人，最低 AC 为 0，作者预算上限为论文的 5%。
- 所有审稿人的固定报价相同，都是论文的 0.5%。因此本轮排名等价于按
  候选人的 AC 排名，不能验证异质报价下的价格竞争或均衡价格。
- 其他参数使用本分支当前 `SimConfig` 默认值；完整配置已写入概要文件。

## 仿真是否正常

1000 个 timestep 均检查通过：每人一次劳动、审稿状态一致、无重复分配、
无自审、份额有限非负且总和为 1、资本记账一致、候选搜索不超过上限。

| 指标 | 结果 |
| --- | ---: |
| 新发表论文 | 703 |
| 最终论文总数（包含初始论文） | 1103 |
| 完成审稿 | 1101 |
| 期末正在审稿 | 2 |
| 期末等待匹配 | 0 |
| 写作时间占比 | 90.54% |
| 审稿时间占比 | 9.46% |
| 好信审稿 | 564（51.23%） |
| 坏信审稿 | 537（48.77%） |

写作与审稿均持续发生，没有观察到集体转向审稿或市场长期积压。但这不表示
90.54% 就是最优或普遍健康的写作比例。

## 等待时间要区分启动库存和新论文

全部成交的平均等待为 8.61 步，95 分位为 42 步。这个数字主要来自初始的
400 篇论文同时进入市场，不能直接解释为正常运行时每篇新论文等待 8.61 步。

| 论文集合 | 成交数 | 平均等待 | 最长等待 |
| --- | ---: | ---: | ---: |
| 初始论文 | 400 | 23.723 步 | 49 步 |
| 本轮新论文 | 703 | 0.013 步 | 1 步 |
| 最后 200 步成交论文 | 147 | 0.007 步 | 1 步 |

最后 200 步写作占比为 93.21%，完成审稿 149 次，好信比例 57.05%。这里的
147 次成交与 149 次完成不同，是因为部分审稿在窗口前已经接单。

## 不同策略的表现

| 指标 | 启发式 agent | 随机 agent |
| --- | ---: | ---: |
| 新发表论文（扣除各组 200 篇初始论文） | 340 | 363 |
| 完成审稿 | 428 | 673 |
| 好信审稿比例 | 89.02% | 27.19% |
| 平均完成审稿努力 | 5.62 | 2.04 |
| 平均最终 AC | 23,229.14 | 23,441.84 |

启发式组明显更认真审稿，但平均最终 AC 比随机组低约 0.91%。随机组完成更多
短审稿，也发表了更多论文。本轮不能支持“更认真审稿自然带来更高资本”的结论，
也不能据此断言随机策略在所有种子下更好。

按已有持有份额口径，两组来自审稿的最终 AC 合计约 4667.07，只占全部 AC
933419.52 的约 0.50%。这说明当前设置下，最终资本主要来自写作与初始论文
持有收益；用 AC 选择审稿人时，选到的并不是一个纯粹的审稿贡献指标。

## 集中程度与可以得出的结论

订单分配 Gini 为 0.292；接单最多的 20% agent 获得了 36.63% 的订单。
最终资本 Gini 为 0.163。订单集中与资本集中是两件事；本轮没有同设置的
旧市场对照，不能仅凭这些绝对值断言新机制增加或降低了不平等。

可以确认：机制能运行，计算与时间预算没有被破坏，新论文能迅速找到审稿人。
仍未证明：按 AC 选人比其他规则更好，或者新机制能激励更多好信审稿。
本轮只有一个种子，而且报价完全相同，不支持价格竞争、长期均衡或真实引用
增益方面的结论。

下一步最有价值的验证是：保留这套初始化和工作策略，比较 AC／报价排序与
同流程随机排序，并让报价具有明确的差异。比较实际审稿增值、作者净收益、
论文产出、等待和订单集中，而不只比较最终 AC。
