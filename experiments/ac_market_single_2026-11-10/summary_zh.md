# AC／报价审稿市场：本轮模拟总结

日期：2026-11-10。分支：`codex/ac-review-market`。
本文件只总结本目录的单轮模拟，不与之前的多种子对照实验混用。
英文对应版本：`summary_en.md`。

## 1. 实现范围与本轮实际测试的内容

市场流程已经实现：审稿人提交报价，作者提出最低 AC 与预算，市场从相应
AC 分组抽取有限候选人，按 AC／报价排序，审稿人确认接单后锁定成交份额。
实际审稿继续使用原来的时间预算、努力决策、论文增值和份额结算规则。

但本轮使用的是固定报价策略：所有审稿人始终报价论文所有权的 0.5%。
因此 AC／报价排名等价于 AC 排名。报价接口存在，不代表动态报价行为已经实现。

本轮检验了固定价格下的抽样、匹配、接单、工作与结算流程；没有检验价格竞争、
自主调价或连续双向拍卖。不存在 best_ask − 0.01 或 best_bid + 0.01 更新。

## 2. 固定参数

| 项目 | 本轮设置 |
| --- | --- |
| 市场机制 | `sampled_bidding` |
| Agent | 启发式 20 人，随机 20 人 |
| RL／DQN | 0 人；没有训练 |
| 时长与种子 | 1000 步；seed=11 |
| 初始论文 | 每人 10 篇，共 400 篇；初始已积累 AC 为 0 |
| 审稿人报价 | 每人固定为整篇论文的 0.5% |
| 作者预算上限 | 整篇论文的 5%，并受现有所有权和论文份额上限约束 |
| 最低审稿人 AC | 0 |
| 每篇论文每轮候选上限 | 5 人；自审、预算等过滤可能使实际人数更少 |
| AC 分桶边界 | 1、10、100、1000；最低与最高区间向外延伸 |
| 价格单位 | 0.0001，即 0.01 个百分点 |
| 审稿模式 | 连续模式 |
| 好信分类门槛 | 审稿努力至少 3；这是模拟分类，不是真实质量认证 |
| 最低有效审稿努力 | 0；没有新增好信才支付的条件 |
| 每个审稿／写作工作步的努力增量 | 各为 1 |
| 审稿增值曲线 | sigmoid |
| 增值持续方式 | permanent |
| 发表规则 | threshold：累计 50 个写作努力单位自动发表 |
| 启发式预测范围 | 30 步 |
| 随机 agent 挂单概率 | 空闲时每步 0.5 |

配置还保存了 `paper_effort_mode=quality_scaled` 与 130–170 的目标范围，
但当前 threshold 发表路径实际以 `continuous_paper_timesteps=50` 判定发表。
不能把本轮描述成每篇论文必须写作 130–170 步。

AC 是市场可观察信号，不是论文份额支付使用的现金。报价是所有权比例，
不是消耗审稿人已有 AC。原有 talent 仍影响生产与策略估计，但不进入市场排名。

## 3. 哪些量会变化

- 审稿人的 AC 随论文收益和持有份额变化；排名使用当轮工作前的 AC 快照。
- 候选人样本、接单对象、审稿努力、完成时间及好／坏信分类会变化。
- 启发式 agent 可因具体论文的预期收益不如写作而拒绝订单。
- 作者的剩余份额、论文收益、已完成审稿数及市场库存会变化。
- 默认作者申请所有符合条件论文的审稿；虽然支持暂不申请的接口，本轮没有
  使用学习型或动态释放策略。预算与最低 AC 标准也不自动适应供需。

## 5. 数据支持的结论

1. 在这组参数下，仿真持续运行，写作没有被审稿挤掉，新论文没有形成期末积压。
   这不证明该写作比例最优，也不证明其他供需规模下一样稳定。
2. 启发式组好信比例更高，但平均 AC 低约 0.91%。这是单个种子的组间观察，
   不是认真审稿降低收益的因果证据。
3. 市场里的支付份额始终是 0.5%，本轮没有观察到价格形成或调价行为。

## 6. 对第二个结果的可能解释

固定 0.5% 份额意味着审稿人只获得该论文额外收益的一小部分，作者保留其余
99.5%。努力可以提升审稿人持有份额的价值，但不会自动增加份额比例。
启发式 agent 每次审稿投入更多努力，因此可能牺牲其他接单和写作机会。

本轮随机组完成更多短审稿，也发表更多论文。按期末持有份额计算，全部来自
审稿的 AC 合计约 4667.07，只占总 AC 933419.52 的约 0.50%；最终 AC 主要
反映自有论文收益与其他资本来源，不是纯粹的审稿贡献指标。

这些因素与观察一致，但没有通过本轮单独隔离。论文质量、收益发生时间、
其他人对自己论文的审稿、30 步预测范围和随机路径也可能影响结果。

## 7. 不能得出的结论与下一步

不能据此说新市场优于旧市场、随机策略普遍更好、好信审稿没有价值，或动态
竞价已经有效。这里的收益是本地 main 的 accrual 模型结果，不是真实引用增量。
本轮也没有同初始化、同种子的旧市场对照。

下一步先明确并实现报价策略，再保持初始化一致，比较 AC／报价选人和同流程
随机选人；使用更多种子，联合衡量论文产出、模型内审稿增值、作者净收益、
等待、劳动分配与订单集中度。不能只用总 AC 或成交数量判断机制是否更好。
